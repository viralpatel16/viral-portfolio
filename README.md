# Viral Patel — Portfolio

Personal portfolio built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Portfolio sections

- Home
- About and education
- Skills
- Projects
- Certifications and internship
- Contact and social profiles

The project uses the existing dark navy, cyan, and violet visual identity.
